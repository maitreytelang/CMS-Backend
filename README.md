
# CMSBackend

A Content Management System REST API built using Java and Spring Boot with JWT-based authentication and role-based authorization.

## Features

- User registration and login
- JWT-based authentication
- Role-based authorization (Admin and Customer)
- Topic management
- Tutorial management
- RESTful APIs

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- MySQL
- JWT
- Maven

## Architecture

Controller → Service → Repository → Database

## Configuration

Set the following environment variables before running:

- DB_URL
- DB_USERNAME
- DB_PASSWORD
- JWT_SECRET

## Running the Project

1. Clone this repository.
2. Configure the required environment variables.
3. Create the MySQL database.
4. Run the application using Eclipse or Maven.
